# funnel_data_source (Resource)

Manages a Funnel data source, which represents a connection to an advertising platform or analytics system. Data sources pull data from external platforms into Funnel for aggregation and analysis.

-> **Note:** `funnel_data_source` is a resource that manages a data source in Funnel. To read an existing Funnel data source, use the `funnel_data_source` data source.

~> **Note:** Before creating this resource, share the platform credential with the System user in Funnel. See the [Credentials guide](/providers/funnel-io/funnel/latest/docs/guides/credentials#data-sources).

## Data source templates

The data from the platform you'll download into Funnel when creating a data source is defined by the template provided. In Funnel there are built in templates but you can also create your own custom ones.
Go into Funnel and navigate to your Subscription overview and the templates section and all templates are listed there. The default view is a list of your custom templates.
Click on the Funnel templates button to see the built in templates. Click on a template and set the `template_id` argument to the Template ID for your platform.

## Remote ID and remote struct

The [data_source_remote_struct](/providers/funnel-io/funnel/latest/docs/guides/data_source_remote_struct) guide lists which of `remote_id` or `remote_struct` each `type` uses, and the format of `remote_struct`.
Set the argument your platform uses. The two are mutually exclusive.

## Example Usage

```terraform
# Google Analytics 4 data source configured with remote_struct
resource "funnel_data_source" "google_analytics" {
  workspace     = var.workspace_id
  type          = "googleanalytics"
  name          = "Google Analytics - With parent"
  template_id   = "funnel:a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4"
  credential_id = var.google_analytics_credential_id
  remote_struct = jsonencode({
    remote_id        = "312456789"
    remote_parent_id = "98765432"
  })

  # Default values
  download_disabled        = false
  exclude_data_from_funnel = false
}

# TikTok Ads data source configured with remote_id
resource "funnel_data_source" "tiktok_ads" {
  workspace     = var.workspace_id
  type          = "tiktok"
  name          = "TikTok Ads - Campaign"
  template_id   = "funnel:b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5"
  remote_id     = "7012345678901234567"
  credential_id = var.tiktok_credential_id
}

# Spotify Ads data source without remote_id or remote_struct
resource "funnel_data_source" "spotify" {
  workspace     = var.workspace_id
  type          = "spotifyads"
  name          = "Spotify Ads"
  template_id   = "funnel:c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6"
  credential_id = var.spotify_credential_id
}

# Custom template example
resource "funnel_data_source" "tiktok_custom" {
  workspace     = var.workspace_id
  type          = "tiktok"
  name          = "TikTok Ads - Custom Template"
  template_id   = "tiktok-d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1"
  remote_id     = "7012345678901234567"
  credential_id = var.tiktok_credential_id
}
```

## Schema

### Required

- `name` (String) The display name for this data source as it will appear in the Funnel interface. Should be descriptive and help identify the account or configuration (e.g., "Google Ads - Main Account").
- `type` (String) The source type identifier, e.g. `adwords` (Google Ads) or `facebookads` (Facebook Ads). See the [data_source_remote_struct](/providers/funnel-io/funnel/latest/docs/guides/data_source_remote_struct) guide for all supported types. Changing this forces a new resource to be created.
- `workspace` (String) The Funnel workspace ID where this data source will be created. Must be exactly 20 characters (letters, digits, `-` and `_`).

### Optional

- `credential_id` (String) The ID of the credential used to authenticate with the external platform. The credential must be shared with the System user. See the [Credentials guide](/providers/funnel-io/funnel/latest/docs/guides/credentials#data-sources).
- `download_disabled` (Boolean) When set to `true`, prevents Funnel from downloading data from this data source. Useful for temporarily pausing data collection without deleting the data source configuration. Defaults to `false`.
- `exclude_data_from_funnel` (Boolean) When set to `true`, excludes data from this source from being included in Funnel aggregations and queries. The data source will still download and store data, but it won't be available for analysis. Could be useful if you want to validate the data before it is used in Funnel. Defaults to `false`.
- `is_demo` (Boolean) When set to `true`, the data source produces demo (test) data in Funnel instead of connecting to the external platform. Defaults to `false`. Changing this forces a new resource to be created.
- `remote_id` (String) The identifier of the account or entity in the source system (e.g., Google Ads customer ID, Facebook Ads account ID). Required for most advertising platforms. Changing this forces a new resource to be created.
- `remote_struct` (String) A JSON-encoded object containing remote identity fields for connectors that require multiple account identifiers. Mutually exclusive with `remote_id`. Changing this forces a new resource to be created. For how `remote_struct` should be formatted for each data source type go to the guide called [data_source_remote_struct](/providers/funnel-io/funnel/latest/docs/guides/data_source_remote_struct).
- `template_id` (String) The template ID that defines what data to collect. Built-in templates use the format `funnel:<connector_prefix>-<slug>` (e.g., `funnel:tiktok-my_template_slug`). Custom templates use the format `<connector_prefix>-<hash>` (e.g., `tiktok-a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4`). Changing this forces a new resource to be created.

### Read-Only

- `id` (String) The unique identifier (key) for this data source in Funnel. This value is generated by Funnel and used for API operations.
- `state` (String) The current operational state of the data source in Funnel (e.g., `OK`, `UNAUTHORIZED`, `INVALID`, `DISABLED`). This is managed by Funnel and reflects the health and status of the data source connection.
